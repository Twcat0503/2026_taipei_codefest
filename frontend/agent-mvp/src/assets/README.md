# Design reference assets

`disaster-example.png` is the example photograph displayed in the supplied
[Town Pass / Care Assistant Figma design](https://www.figma.com/design/eg7CaqCSXBtZaRtxWgddYv/?node-id=2004-1347).
It is used only in the explicitly labelled, local disaster-report UI demonstration.
It does not represent a current incident or the user's location, and no image analysis is performed.

The welcome illustration is imported from the repository's existing Town Pass SVG asset.
